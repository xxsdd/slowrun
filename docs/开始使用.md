# 开始使用慢慢跑

慢慢跑是 SwiftUI 原生 iPhone App，最低 iOS 17。公开源码版本为 0.3.0（build 15）。演示网页是视频展示页，打开网页不会开始记录跑步。

## Mac 开发

用 Xcode 16 或更新版本打开 SlowRun.xcodeproj，选择 SlowRun scheme。安装到自己的 iPhone 时，为应用和实时活动扩展配置自己的签名团队及唯一 Bundle ID。首次运行需要允许定位、运动与健身权限；锁屏卡片需要允许实时活动。

```sh
swift test --package-path RunCore
bash scripts/verify-mac.sh
```

## Windows 构建

Fork 仓库，在 Actions 中手动运行 Build iPhone install package。macOS runner 会运行核心测试并编译，构建结果提供 SlowRun-unsigned.ipa。这个文件尚未签名，需要用自己的 Apple 账户及支持本机签名的安装工具签名、安装；它不是 App Store 或 TestFlight 分发包。

更新自己已经安装的 App 时，保持相同的签名身份和 Bundle ID，先备份数据再覆盖升级。不要用他人的签名包或账户。

## 训练

开始页选择九周新手课程、自由跑或距离跑。新手课程完成后会推荐下一节；自由跑可以自定义跑/走时长，无限循环到你主动结束。结束时可以立即保存，也可以先步行放松。热身、正式训练和放松分别记录，全程是三段之和。

配速、公里与阶段提示使用已内置的微软短语在手机本地组合，不需要在跑步中请求语音服务。设置中可调整配速播报开关、间隔及目标配速。热量是根据体重、活动强度和时间计算的粗略活动消耗估算；GPS、计步和步频的准确性取决于设备及环境。

## 可选 AI 复盘

基础记录和离线播报不需要 AI。AI 只在主动点击生成时调用，公开版本没有预设个人服务地址，也没有预置任何密钥。需要时自行部署 service/ 或 service/cloud/，然后在 App 高级设置填写自己的服务地址和访问令牌。只有汇总统计发送到复盘服务，接口拒绝 GPS 轨迹字段。

本项目不测心率，不连接手环。
