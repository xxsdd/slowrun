# 语音与数据

训练提示使用确定的手机端规则，模型不负责实时计时或定位。

- 固定提示：热身、开始跑步/自由跑、切到步行、放松、结束等。
- 配速播报：开关和间隔可设置；动态数字由内置微软短语拼接。与目标配速相差不超过一分钟时评价正常。
- 每公里：正式训练的本公里用时与累计训练信息；热身和放松单独计算。
- 动作提醒：开启后按累计跑步时间每三分钟播报；步行时不播。
- 录音缺失或不支持的数字：按设置使用系统语音备用，或保持静音。

内置资源包含9条固定语音和190段数字/短语。只检查文件与哈希，不发起合成请求：

```sh
python scripts/prepare_voice_pack.py
python scripts/prepare_number_voice_pack.py
```

只有明确使用 --generate 才会请求自己配置的语音服务。请自行管理 Azure Speech 及模型服务额度，不要把任何密钥提交到仓库。

训练记录和精确路线保存在自己的手机。公开仓库与演示站点不包含个人 GPS 记录、账户凭据、签名证书或备份。锁屏保留当前阶段的距离、配速、用时与倒计时；步频、全程步数及热量在 App 内查看。
